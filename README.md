# 🏆 Sports Console

An Angular-based moderation console built as part of the **Buzzer Developer Onboarding** process.

## 🚀 Live Demo

🔗 https://sports-console.vercel.app/

- Angular (Standalone Components)
- TypeScript
- SCSS
